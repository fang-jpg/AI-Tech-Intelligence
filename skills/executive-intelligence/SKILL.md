# Executive Intelligence

1. Load the company/institution, people, and source registries before searching.
2. Prefer official domains and official code repositories. Treat third-party results as discovery leads, not final evidence.
3. Separate source discovery, evidence extraction, outlook synthesis, and report export.
4. Never attribute a statement to a named person unless the source explicitly connects the person and statement.
5. Label search excerpts separately from full-page evidence.
6. Quantified forecasts must include an as-of date, probability range, time horizon, observable leading indicator, numeric or dated threshold, and falsification criterion.
7. Do not invent performance gains. Leave change-magnitude fields empty when no numerical baseline exists.
8. Low-evidence records must use wide, low probability ranges and remain visibly flagged for review.
9. Detect exact and near-duplicate outlooks across entities. Rewrite generic conclusions around entity-specific projects or mark them for review.
10. Export actual analysis-model metadata, not the requested or discovery model name.
11. Verify row counts, URLs, probability constraints, stale dates, duplicate rates, and spreadsheet error values before delivery.
